## 📖 About the Repository
Curated by **Snehal Singh**, this repository is a structured learning journey designed to take a programmer from **Python Basics** to **Advanced Problem Solving**. It serves as a centralized hub for syntax practice, algorithmic logic, and real-world mini-applications.



## 📂 Repository Structure

| Folder | Content Description | Target Skill |
| :--- | :--- | :--- |
| **Topics** | Fundamental concepts (Loops, Lists, Dicts, OOP). | Syntax Mastery |
| **Practice Questions** | Logical puzzles and interview-style problems. | Algorithm Building |
| **Mini Projects** | Functional scripts and automation tools. | Real-world Application |

<hr />

## 🛠️ Key Features
* **Topic-wise Learning:** Every Python concept is isolated for better focus and clarity.
* **Documented Code:** Clean scripts with comments explaining the *Why* behind the *How*.
* **Logical Progression:** Questions move from simple arithmetic to complex data structures.
* **Open for Contribution:** Built as a community resource for Python enthusiasts.



<hr />

## ⚙️ Getting Started

### 1. Clone the Repository
```bash
git clone https://github.com/coderun13/python.git
```
2. Navigate and Execute
```bash
# Example: Running a script from the Topics folder
cd Topics
python script_name.py
```

3. Contribution Workflow
```bash
# 1. Fork the repo
# 2. Create your Feature Branch
git checkout -b feature/NewQuestion
# 3. Commit your changes
git commit -m 'Add new Python logic'
# 4. Push to the Branch
git push origin feature/NewQuestion
```
